# Naming Playbook

Use this when the addon has no prior repository context.

## Objective
Pick a name that is clear in chat commands, memorable in addon lists, and descriptive in CurseForge search.

## Process
1. Write a one-sentence product intent.
2. Extract 3-5 core words from the intent.
3. Combine words into 8-12 candidate names.
4. Remove names that are too generic or hard to type.
5. Keep a final shortlist of 3 names with rationale.

## Heuristics
- Prefer 1-2 words, TitleCase, no special characters.
- Avoid overloading common names like "DamageMeter".
- Validate readability in slash command form.
- Favor names that imply behavior (Pulse, Window, Trace, Scope).

## Output format
- Candidate list (8-12)
- Top 3 picks with one-line rationale each
- Selected final name
