# WhisperTabs

Auto-open incoming whispers as separate tabs in the default WoW chat window — one tab per conversation.

Built for TBC Classic (Interface 2.5.6).

## Install

1. Download the latest release from [Releases](https://github.com/lemillermicrosoft/WhisperTabs/releases) or CurseForge.
2. Extract `WhisperTabs/` into `World of Warcraft\_anniversary_\Interface\AddOns\`.
3. Restart the client or `/reload`.

## Usage

- Whispers auto-open a new chat tab per correspondent.
- `/whispertabs` or `/wtabs` — config / help.
